# Smart File Organizer Download Site

Static Vercel-ready download website for Smart File Organizer v2.1.0.

## Deploy to Vercel
Import this folder/repository into Vercel. No build command is required for the static site.

The Windows installer is included at:
`public/downloads/Smart-File-Organizer-Setup-2.1.0.exe`

The site includes the approved app icon and the supplied application screenshots.
