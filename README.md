# Smart File Organizer

Smart File Organizer is a Windows desktop application I built to help keep my Downloads folder clean and organized automatically.

I created it with a simple goal: instead of manually moving downloaded files into different folders, the app should do the organization for me.

## What it does

- Automatically organizes files in my Downloads folder
- Sorts files into categories such as Images, Videos, Music, Documents, Archives, Applications, and Others
- Supports Excel and CSV files under Documents
- Can scan existing files and organize them
- Shows scan progress while working
- Detects duplicate files
- Keeps an organization history
- Supports undo for previous organization actions
- Can run in the background
- Supports Windows startup
- Shows notifications when files are organized
- Includes settings for customizing how files are sorted
- Includes a dashboard for viewing organization statistics
